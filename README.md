# Daily Report Management App

P&F Cares 병원 방문 기록 관리 시스템

## 🚀 기능

- ✅ 대리점별 병원 관리
- ✅ 병원 선택 시 전체 방문 이력 표시
- ✅ 일일 리포트 입력/저장/삭제
- ✅ 실시간 데이터 동기화

## 📚 기술 스택

- Frontend: Next.js + React
- Backend: Supabase
- Database: PostgreSQL
- Hosting: Vercel

## 🎯 사용법

1. 왼쪽에서 대리점 선택
2. 중앙에서 병원 선택 (이력 표시)
3. 오른쪽에서 Daily Report 입력
4. 저장 클릭
